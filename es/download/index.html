Descargar Pyloxa para Windows

Gratis y sin cuenta. Pyloxa ejecuta las CLI de Claude Code y Codex que ya usas, con tus propias suscripciones o claves de API.

La descarga ha comenzado. Si no pasa nada, usa el botón de abajo.

Descargar el instalador v0.2.0 · 130.5 MB · Windows 10 y 11, 64 bits

12 versiones publicadas desde noviembre de 2026, cada una con notas de la versión y suma SHA-256.

Instálalo en cuatro pasos

  1. Ejecuta el instaladorEl instalador todavía no tiene firma de código, así que Windows puede decir que protegió tu PC. Elige “Más información” y luego “Ejecutar de todas formas”.
  2. Deja que la guía de configuración revise tu PCComprueba git (obligatorio) y Node.js (opcional). Si falta alguno, muestra el comando de winget o la página de descarga oficial. Con Node.js, instala Claude Code o Codex CLI con el comando oficial de npm cuando lo confirmas.
  3. Inicia sesión en tus agentesInicia sesión en Claude Code o Codex con tu propia suscripción, o añade una clave de API. Pyloxa nunca lee, copia ni envía los inicios de sesión de tus CLI.
  4. Haz una pruebaAntes de abrir tu propio proyecto, prueba Pyloxa con un pequeño proyecto de ejemplo que esconde un error. La prueba necesita Node.js y nunca toca tus proyectos, no hace push ni abre PR.

Qué necesitas

  • Windows 10 u 11, 64 bits
  • Git for Windows 2.30 o posterior
  • Claude Code o Codex CLI, con sesión iniciada con tu propia suscripción o con una clave de API. Con los dos, Pyloxa puede repartir el trabajo y pasar el relevo cuando a uno se le acaba la cuota.
  • Node.js 22 o posterior, solo si quieres que la guía de configuración instale las CLI por ti o hacer la prueba

La edición gratuita no necesita cuenta, y Pyloxa nunca nos envía tu código ni tus prompts.
