Claude Code says “usage limit reached”. Now what?

How Claude Code limits work on a Pro, Max or Ultra subscription, how to see when yours resets, and how to keep the work moving without losing it or breaking the terms.

Updated November 19, 2026

Short answer

On a Pro or Max plan, Claude Code shares one allowance with claude.ai: a session limit that resets five hours after your first message, plus a weekly limit. When you hit it, run /usage to see when it resets. You can then wait (recent Claude Code versions continue the interrupted task on their own after the reset), turn on usage credits billed at API rates, switch Claude Code to a Console API key, or commit the work and hand it to another agent. Rotating several accounts to dodge the limit goes against Anthropic’s terms and Usage Policy.

What “usage limit reached” means in Claude Code

A Pro, Max or Ultra subscription covers claude.ai, Claude Desktop and Claude Code with one shared allowance. Everything you do in any of them counts against the same limits.

  • Session limit: the period starts with your first message and resets in full five hours later. Verified Ultra accounts have no five-hour limit.
  • Weekly limit: across all models, with a fixed weekly reset time for your account. Max and Ultra also have a separate weekly limit for Fable models.
  • Both at once: usage counts against the session and weekly allowances at the same time, so one heavy burst can use up the week before the session resets.

Anthropic publishes no message or token counts for these limits and may adjust them. Model, effort level, conversation length and tools all change how fast you use them.

MessageWhat it means

You've hit your weekly limit · resets Mon 12:00amThe weekly allowance is used up. Switching models doesn’t help.

How do I see my usage and when it resets?

  • /usage (also /cost, /stats): plan usage bars, reset times, and a breakdown of what used your allowance, with suggested fixes. The breakdown covers this computer only.
  • /status: which account and login method is active, so you know whether you’re on your subscription or an API key.
  • claude.ai → Settings → Usage: the current session, time remaining and your next weekly reset, across every Claude app.

Claude Code warns before you run out, with a message such as You've used 85% of your session limit · resets 3:45pm. That’s the moment to commit and write a handoff note, while Claude can still help.

What can I do when the limit hits?

  1. Wait for the resetSince v2.1.234, an interactive session signed in with a subscription continues the task by itself after the reset, as long as the session stays open: Continuing automatically at 3:45pm · Esc to cancel. For a reset more than 24 hours away (often the weekly limit), pick “Wait here, then continue automatically” from /rate-limit-options.
  2. Turn on usage creditsUsage credits (formerly “extra usage”) let Pro, Max and Ultra keep working past the limit. Run /usage-credits or open claude.ai → Settings → Usage, turn on Usage credits, set a monthly spend limit and buy credits. They’re prepaid, charged at standard API rates on top of your subscription, and non-refundable.
  3. Switch Claude Code to an API keySet ANTHROPIC_API_KEY to a Claude Console key and approve it when asked, or /login with a Console account. Every token is then billed at API rates, with no reset window. To go back, remove the variable and check /status; a forgotten key keeps billing you.
  4. Use a lighter modelThis gets you past an Opus or Sonnet limit and makes the rest of the allowance last. Anthropic suggests Sonnet for most coding and Opus for hard reasoning; /effort lowers thinking.
  5. Upgrade the planPro to Max, or Max to Ultra, raises the base limits. Check current plans at claude.com/pricing.

How do I make the limit last longer?

Claude Code sends the whole conversation with every request, so context size drives usage. From Anthropic’s cost guide:

  • /clear between unrelated tasks. It costs nothing. /rename first if you want to /resume later.
  • /compact with focus instructions when you need continuity. Compacting a big context is itself a large request.
  • Ask for specific changes. “Add input validation to the login function in auth.ts” reads far fewer files than “improve this codebase”.
  • Keep CLAUDE.md short (the docs suggest under 200 lines) and move rarely used instructions into skills.
  • Disable unused MCP servers with /mcp; /context shows what fills the window.
  • Watch idle sessions. Loops, scheduled tasks and goal check-ins can send your full context while the session sits idle, and every subagent makes its own requests.

How do I hand unfinished work to Codex or another agent?

Another agent on its own plan, such as Codex CLI signed in with your ChatGPT account, can carry on. It sees your files and git, not Claude’s conversation, so put everything there.

  1. Put the work on a branchCheck git status so nothing secret gets committed, then commit what’s there, even if it doesn’t build yet.
  2. Write a short handoff noteGoal, what’s done, what’s left, which files matter, how to test, and known breakage. Ask Claude to write it when the usage warning appears; after the limit, write it yourself.
  3. Give both agents the same instructionsCodex reads AGENTS.md before it starts. Claude Code reads AGENTS.md when there’s no CLAUDE.md, or put @AGENTS.md on the first line of CLAUDE.md so both read one file.
  4. Start the next agent on the noteOpen the repo in Codex and ask it to read the note and continue. Check /status in Codex: it has its own limits.
git status
git switch -c wip/limit-handoff
git add -A
git commit -m "WIP: handoff from Claude Code (usage limit)"
codex "Read HANDOFF.md and AGENTS.md, run the tests, then continue the remaining items."

Can I use several Claude accounts to get around the limit?

Don’t. Pro, Max and Ultra fall under Anthropic’s Consumer Terms, which forbid sharing your account login with anyone else. Anthropic’s Usage Policy, under “Do Not Abuse Our Platform”, forbids intentionally bypassing restrictions built into its products and creating multiple accounts to avoid detection. Rotating accounts to dodge a limit, or sharing one subscription, risks every account involved. If one plan isn’t enough, use usage credits, a bigger plan, an API key, or another vendor’s agent on your own plan.

FAQ

When does the Claude Code usage limit reset?
The session limit resets five hours after the first message of that session. The weekly limit resets at a fixed weekly time for your account. The error message shows the reset time, and /usage or claude.ai → Settings → Usage show both.
Do claude.ai chats and Claude Code share the same limit?
Yes. On Pro, Max and Ultra, activity in claude.ai, Claude Desktop and Claude Code all counts toward the same session and weekly limits.
Does switching to Sonnet or Haiku get me past the limit?
Not for the session or weekly limit, which apply to all models. It does help after an Opus or Sonnet limit message, and a lighter model makes the remaining allowance last longer.
Will Claude Code charge my card automatically when I hit the limit?
Not on a subscription unless you turn on usage credits and buy them. It does bill per token if ANTHROPIC_API_KEY is set and approved, so check /status if you’re unsure which one you’re on.
Can Codex pick up exactly where Claude Code stopped?
It picks up from the files and the git branch, not from Claude’s conversation. That’s why the committed branch and a short handoff note matter: they hold the context the next agent needs.
