# MAD website

Static site for MAD: `index.html` (English) and `zh-TW/index.html` (繁體中文). No build step; serve the folder as is.

- Download links point to the latest release in [MAD-Releases](https://github.com/eric861129/MAD-Releases/releases/latest).
- `legal/` holds copies of the EULA and third-party notices shipped with the installer; update them with each release.
- Screenshots in `assets/shots/` are taken from the app with demo data.
