# Pyloxa website

Static site for Pyloxa: `index.html` (English) and `zh-TW/index.html` (繁體中文). No build step; serve the folder as is.

- Download links point to the latest release in [Pyloxa-Releases](https://github.com/eric861129/Pyloxa-Releases/releases/latest).
- Each release: update the version in the page text, in `softwareVersion` of the JSON-LD block in each page's `<head>`, and `<lastmod>` in `sitemap.xml`. Then regenerate the changelog pages (`changelog/` and `zh-TW/changelog/`) from the release notes: `node scripts/build-changelog.mjs ../Pyloxa-Releases`. Commit the release notes in Pyloxa-Releases first; the release date is the date of that commit.
- `assets/og-en.png` and `assets/og-zh.png` are the 1200×630 link-preview images (rendered from the wordmark and `assets/shots/<lang>/plan-card.png`). Icons (`favicon.ico`, `assets/favicon.svg`, `assets/apple-touch-icon.png`, `assets/site.webmanifest`) come from the app repo's `brand/web/`.
- Page views are counted with Cloudflare Web Analytics (cookieless; manual JS snippet before `</body>` on each page, because the site is DNS-only and not proxied). The footer says so. Search Console uses the domain property `sc-domain:pyloxa.com` with `sitemap.xml` submitted. Google Analytics 4 property "Pyloxa" (account Chiyu-GitHub-Project, measurement ID `G-PWKKJHQV92`) is in each page's `<head>`: advertising features off, analytics cookies denied by default in the EEA, UK and Switzerland (no consent banner), plus `download_click` (release links) and `generate_lead` (early-bird form) events. Bing Webmaster Tools is verified by the `msvalidate.01` meta tag in `index.html`; keep it. After each Pages build, `.github/workflows/indexnow.yml` pings IndexNow (key file `c11e770d29e531bffe32789c008327a4.txt` at the root; keep it). Add new pages to its `urlList`.
- `privacy/` and `zh-TW/privacy/` are the privacy policy (hand-written; linked from the footer). Update both, and the date at the top, whenever the site or the app starts collecting or sending something new, and before Pro sign-in and payments (D-78) or the opt-in usage statistics (D-79) ship.
- `legal/` holds copies of the EULA and third-party notices shipped with the installer; update them with each release.
- Screenshots in `assets/shots/` are taken from the app with demo data.
- Screen recordings in `assets/video/<lang>/` (VP9 WebM, poster = last frame) are recorded from the app with demo data; waits for agents are cut out. They play when scrolled into view and pause on click.
- The Pro early-bird form posts to the endpoint in `<meta name="pyloxa:waitlist">` on each page (Buttondown's `https://buttondown.com/api/emails/embed-subscribe/<username>`). While it is empty, the pricing table shows "sign-up opens soon" instead of the form.
