Short answer

The Codex app is OpenAI’s first-party desktop app for Codex. Since July 9, 2026 it has been part of the ChatGPT desktop app on macOS and Windows, with Linux in preview. It runs parallel Codex chats locally, in Git worktrees or in the cloud, with diff and pull request review, scheduled tasks and phone access. Pyloxa is a separate Windows app, not affiliated with OpenAI, that gets Codex CLI and Claude Code to work on one plan under your routing rules and runs your verification commands itself. If you only use Codex, the Codex app is likely the better fit.

What the Codex app does well

  • Local, worktree or cloud, per chat. Handoff moves a chat between Local and Worktree and handles the Git steps. Setup scripts prepare new worktrees, and actions put commands such as your test suite in the top bar.
  • Review built in. The review pane takes inline comments and lets you stage, revert, commit, push and open a pull request. /review reviews a branch or uncommitted changes without touching your files. Code Review shows GitHub pull requests with their checks, and automatic cloud reviews can comment before you open them.
  • Work that keeps going without you. Cloud tasks run while your computer sleeps. Scheduled tasks run in your project or a background worktree and report back in Scheduled.
  • Reach from anywhere. From ChatGPT on iOS or Android you can start chats on a connected computer, approve commands and review diffs. The app can also open projects over SSH.

Where Pyloxa is different

Pyloxa doesn’t replace Codex. It starts the official Codex CLI and Claude Code as you would in a terminal, and coordinates them on one project.

  • Two vendors on one plan. A brain agent splits a request into phases and tasks, and your routing rules send each task to Codex CLI or Claude Code. The Codex app’s docs describe importing setup from Claude Code, not running it. See Workflow.
  • Pyloxa runs the checks itself. After each task it runs the verification commands you approved, such as npm run test, and checks that changed files stay within the plan’s write scope. An agent saying it’s done never counts as passing. Another vendor’s agent can cross-test the work by adding tests, and the command result decides. Cross-testing is on request in the free edition and automatic in Pro.
  • Another agent takes over when quota runs out. When Codex runs out of quota, Pyloxa proposes the fallback from your rules, and after you confirm, Claude Code continues from the files already changed. See Quota & fallback.
  • Your folder stays yours. Agents work only in Pyloxa’s worktrees, and nothing is merged or pushed until you choose Merge into current branch or Create branch and open PR. A verification card can go into the PR description.

Limits to know: Pyloxa is Windows only and closed source, and its installer is not code-signed, so SmartScreen may warn on first run. Its agents run on your own PC, and quitting Pyloxa stops them.

Which one to choose

  • Choose the Codex app if Codex is your only coding agent, you use a Mac or Linux, or you want cloud tasks, phone access, SSH projects, scheduled tasks or pull request review from the same app.
  • Choose Pyloxa if you work on Windows with both Codex and Claude Code and want one plan split between them by your rules, your own commands deciding what passes, and one agent taking over when the other runs out of quota.

Can you use both?

Yes. Pyloxa uses Codex CLI, not the app: use the Codex app for Codex chats, cloud tasks and pull request review, and Pyloxa for plans split across Codex and Claude Code. If Codex CLI is signed in with ChatGPT, its work in Pyloxa counts against the same plan’s usage; API-key sessions are billed separately. Git lets a branch be checked out in only one worktree at a time, so don’t point both at the same branch or files at once.

FAQ

Is there a Codex app for Windows?
Yes. The Codex app came to Windows on March 4, 2026, and on July 9, 2026 Codex became part of the ChatGPT desktop app, keeping existing projects and settings. It runs natively in PowerShell with a Windows sandbox, or in WSL2.
Can the Codex app run Claude Code?
OpenAI’s docs describe importing setup and recent chats from Claude Code, Claude Cowork and Cursor, not running those agents. Pyloxa runs Claude Code and Codex CLI side by side on one plan.
Does the Codex app need a paid plan?
No. OpenAI lists Codex as included in every ChatGPT plan from Free to Enterprise. How much you can do depends on the plan, model and task.
Does Pyloxa work with my ChatGPT subscription?
Yes. Sign in to Codex CLI with codex login, or use an OpenAI Platform API key. Pyloxa never reads, copies or sends your tokens. See Connect your agents.
Is Pyloxa available on macOS?
No. Pyloxa runs on Windows 10 and 11, 64-bit. On a Mac, the Codex app is available.
