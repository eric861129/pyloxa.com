簡短回答

Codex App 是 OpenAI 自家的 Codex 桌面 App。從 2026 年 7 月 9 日起，它併入 macOS 與 Windows 上的 ChatGPT 桌面 App，Linux 版則在預覽中。它可以同時開好幾個 Codex 對話，跑在本機、Git worktree 或雲端，並內建 diff 與 Pull Request 審查、排程工作和手機遠端操作。Pyloxa 是另一個 Windows App，和 OpenAI 沒有關係：它讓 Codex CLI 和 Claude Code 依你的派工規則做同一份計畫，並由 Pyloxa 自己執行你的驗證命令。如果你只用 Codex，Codex App 多半比較適合你。

Codex App 做得好的地方

  • 每個對話自選本機、worktree 或雲端。Handoff 可以把對話在 Local 和 Worktree 之間移動，Git 操作由它處理。設定腳本會幫新的 worktree 準備環境，動作（actions）把測試之類的常用命令放在上方工具列。
  • 內建審查。審查窗格可以加行內註解，也能 stage、revert、commit、push 和開 Pull Request。/review 審查某個分支或還沒 commit 的改動，不會動到你的檔案。Code Review 顯示 GitHub 的 Pull Request 與它的檢查結果，自動雲端審查可以在你打開之前就先留下意見。
  • 你不在時工作照樣進行。雲端工作在電腦睡眠時也會繼續跑。排程工作在你的專案或背景 worktree 裡執行，結果回報到 Scheduled。
  • 在哪裡都能接手。用 iOS 或 Android 上的 ChatGPT，就能在連線的電腦上開新對話、核准命令、看 diff。App 也能透過 SSH 開啟遠端主機上的專案。

Pyloxa 的不同之處

Pyloxa 不是要取代 Codex。它像你在終端機裡一樣啟動官方的 Codex CLI 與 Claude Code，再讓它們在同一個專案裡分工。

  • 兩家的 Agent 做同一份計畫。大腦把需求拆成階段與工作，你的派工規則把每個工作交給 Codex CLI 或 Claude Code。Codex App 的文件說明的是從 Claude Code 匯入設定，不是執行它。詳見工作流程。
  • Pyloxa 自己驗收。每個工作完成後，它會執行你核准的驗證命令（例如 npm run test），並檢查改動的檔案有沒有超出計畫的寫入範圍。Agent 說「做完了」從來不算通過。另一家的 Agent 可以新增測試來交叉測試，以命令的結果為準。免費版要你按下才交叉測試，Pro 可以自動進行。
  • 額度用完時換另一個 Agent 接手。Codex 額度用完時，Pyloxa 依你的規則提出備援，你確認後，Claude Code 從已經改好的檔案繼續做。詳見額度與備援。
  • 你的資料夾不會被動到。Agent 只在 Pyloxa 的 worktree 裡工作，直到你按「合併到目前分支」或「建立分支並開 PR」之前，什麼都不會合併或推送。驗證報告卡可以附在 PR 說明裡。

先說清楚的限制：Pyloxa 只支援 Windows、不開源，安裝檔還沒有程式碼簽章，所以第一次執行時 SmartScreen 可能會跳警告。它的 Agent 跑在你自己的電腦上，結束 Pyloxa 就會停止它們。

該選哪一個

  • 選 Codex App，如果你只用 Codex 寫程式、用的是 Mac 或 Linux，或想在同一個 App 裡用雲端工作、手機遠端、SSH 專案、排程工作或 Pull Request 審查。
  • 選 Pyloxa，如果你在 Windows 上同時用 Codex 和 Claude Code，想讓一份計畫依你的規則分給兩邊，由你自己的命令決定什麼算通過，而且一邊額度用完時由另一邊接手。

可以兩個一起用嗎？

可以。Pyloxa 用的是 Codex CLI，不是 Codex App：Codex 對話、雲端工作與 Pull Request 審查用 Codex App，要讓 Codex 和 Claude Code 分工的計畫用 Pyloxa。Codex CLI 用 ChatGPT 帳號登入時，它在 Pyloxa 裡的用量算在同一個方案；API Key 的 Session 另外計費。Git 規定一個分支同一時間只能在一個 worktree 裡 checkout，所以不要讓兩邊同時處理同一個分支或同一批檔案。

常見問題

Codex App 有 Windows 版嗎？
有。Codex App 在 2026 年 3 月 4 日推出 Windows 版，2026 年 7 月 9 日 Codex 併入 ChatGPT 桌面 App，原有的專案與設定都會保留。它可以用原生 PowerShell 搭配 Windows 沙箱執行，也可以跑在 WSL2。
Codex App 能跑 Claude Code 嗎？
OpenAI 的文件說明的是從 Claude Code、Claude Cowork 與 Cursor 匯入設定和最近的對話，不是執行這些 Agent。Pyloxa 則讓 Claude Code 和 Codex CLI 在同一份計畫裡一起工作。
Codex App 需要付費方案嗎？
不需要。OpenAI 列出從 Free 到 Enterprise 的每個 ChatGPT 方案都包含 Codex。能用多少，要看方案、模型和工作內容。
Pyloxa 可以用我的 ChatGPT 訂閱嗎？
可以。在終端機用 codex login 登入 Codex CLI，或改用 OpenAI Platform 的 API Key。Pyloxa 不會讀取、複製或傳送你的 token。詳見連接 Agent。
Pyloxa 有 macOS 版嗎？
沒有。Pyloxa 支援 Windows 10 與 11，64 位元。在 Mac 上可以用 Codex App。
