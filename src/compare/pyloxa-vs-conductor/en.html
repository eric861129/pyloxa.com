Short answer

Conductor is a free macOS app for running Claude Code, Codex, Cursor and OpenCode agents in parallel workspaces, each a git worktree, with diff, pull request and checks views. Its install page says it is not available for Windows or Linux yet (checked 2026-11-19). Pyloxa is a free, closed-source Windows 10 and 11 app where a brain agent plans the work, your rules send each task to Claude Code or Codex, and Pyloxa runs your test commands itself before a result counts. On a Mac, Conductor is a strong fit if you want to drive and review each agent yourself; on Windows, Conductor isn’t an option today and Pyloxa is one alternative.

What Conductor does well

  • Review in one window. The diff viewer filters by commit and sends your comments on changed lines to the agent. GitHub review comments appear in the app, and the Checks tab gathers PR details, CI and status checks, deployments and todos before you merge.
  • Workspace plumbing. Setup scripts prepare each new worktree, run actions start your app or test watcher, archive scripts clean up, gitignored files such as .env.local can be copied in, and each workspace gets ten ports of its own.
  • Many agents and providers. Four harnesses with a model picker per chat. Codex can use your ChatGPT plan through Sign in with ChatGPT; Claude Code can use your Claude Pro or Max login, an API key, Bedrock or a gateway.
  • Work away from the desk. Cloud workspaces keep running after you close the app, the iOS app lets you chat with agents and merge PRs, and remote control drives your Mac from an iPhone.
  • Flexible parallel patterns. One workspace per issue, or several agents in one workspace, and since 0.95.0 agents can create workspaces and message other agents.

Where Pyloxa is different

A plan and rules decide who does what. You describe the work once; the brain splits it into phases and tasks, and routing rules you write, such as “backend tasks go to Codex”, pick the agent for each. The workflow page has five templates and your own stages.

Pyloxa runs the checks itself. An agent saying it is done isn’t enough. After each task Pyloxa runs the verification commands you approved and checks the plan’s write scope, and each phase ends with a gate on the combined result. Another vendor’s agent can test the work, adding tests only, and the command result decides (on request in the free edition, automatic in Pro). Conductor’s docs describe showing CI, status checks and todos before merge; they don’t describe the app running your test commands to accept or reject a result.

Quota takeovers. When a CLI runs out of quota, Pyloxa stops sending it work and offers the fallback agent from your rules, which continues from the files already changed once you confirm. See Quota & fallback.

What Conductor documents and Pyloxa doesn’t: Cursor and OpenCode, cloud workspaces, a phone app, setup and run scripts, and line comments on a diff. Pyloxa’s own limits: closed source, Windows only, an installer that isn’t code-signed (SmartScreen may warn), and agents that stop when you quit it. The free edition runs one project at a time, and Claude Code on a subscription takes one task at a time.

Which one to choose

  • Choose Conductor if you work on a Mac; you like to start each agent yourself and review its diff, checks and PR in one window; you want Cursor, OpenCode, Bedrock or OpenRouter; or you want cloud workspaces and an iPhone app.
  • Choose Pyloxa if you work on Windows 10 or 11; you want one request turned into a plan that rules route between Claude Code and Codex; you want a result to count only when your own commands pass, with another vendor’s agent testing it; and you want a confirmed takeover when one CLI runs out of quota.

Can you use both?

Not on one computer: Conductor runs on macOS and Pyloxa on Windows. With a Mac and a Windows PC, you can use each against the same GitHub repository. Both work on their own branches, so their work meets in pull requests. If both use the same Claude or ChatGPT plan, they share its usage limits.

FAQ

Is there a Conductor for Windows?
Not as of 2026-11-19. Conductor’s install page says it is available for macOS, is not available for Windows or Linux yet, and offers a sign-up to hear when it is.
What is a Conductor alternative for Windows?
Pyloxa is one: a Windows 10 and 11 app that runs Claude Code and Codex CLI in separate git worktrees. It isn’t a port of Conductor. It is built around a plan, routing rules and checks it runs itself, and it doesn’t run Cursor or OpenCode or offer cloud workspaces. To run the CLIs on Windows yourself, see Claude Code and Codex CLI on Windows.
Does Conductor run Codex with a ChatGPT plan?
Yes. Codex is bundled, and since 0.89.0 you can choose Continue with ChatGPT in Settings → Agents → Codex; an existing codex login or an API key also works. Pyloxa runs Codex CLI with codex login or an OpenAI Platform API key.
Is Conductor free?
The app is free, and model usage is billed by your provider. Its FAQ says it plans to charge for collaboration features later. Cloud workspaces need a Pro, Teams or Enterprise plan, with no extra cloud fee for now. Pyloxa’s free edition stays free; Pro is US$79 a year and in a free preview.
