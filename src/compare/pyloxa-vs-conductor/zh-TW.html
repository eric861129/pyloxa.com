簡短回答

Conductor 是免費的 macOS App，可以平行執行 Claude Code、Codex、Cursor 與 OpenCode，每個工作區是一個 git worktree，並提供 diff、pull request 與檢查畫面。它的安裝頁寫著目前還沒有 Windows 與 Linux 版（2026-11-19 查證）。Pyloxa 是免費、不開源的 Windows 10/11 App：大腦規劃工作，依你的規則把每個工作派給 Claude Code 或 Codex，Pyloxa 自己跑你的測試命令，通過了才算數。用 Mac、想自己操作與審查每個 Agent，Conductor 很適合；用 Windows 的話，目前沒有 Conductor 可用，Pyloxa 是其中一個替代選擇。

Conductor 做得好的地方

  • 在同一個視窗審查。diff 檢視器可以依 commit 篩選，你在改動行上的留言會直接交給 Agent。GitHub 的審查留言也會出現在 App 裡，Checks 分頁在合併前把 PR 資訊、CI 與狀態檢查、部署與待辦集中在一起。
  • 工作區的周邊設定。setup 腳本準備每個新的 worktree，run 動作啟動你的 App 或測試監看，archive 腳本負責清理；.env.local 這類被 git 忽略的檔案可以複製進去，每個工作區還有自己的十個連接埠。
  • Agent 與服務商的選擇多。四種 harness，每個對話都能選模型。Codex 可以透過 Sign in with ChatGPT 用你的 ChatGPT 方案；Claude Code 可以用你的 Claude Pro 或 Max 登入、API Key、Bedrock 或 gateway。
  • 離開座位也能看。雲端工作區在關掉 App 後仍會繼續，iOS App 可以和 Agent 對話、合併 PR，遠端控制可以用 iPhone 操作你的 Mac。
  • 平行工作的方式有彈性。一個 issue 一個工作區，或同一個工作區放好幾個 Agent；從 0.95.0 起，Agent 也能自己開工作區、傳訊息給其他 Agent。

Pyloxa 的不同之處

由計畫與規則決定誰做什麼。需求只要說一次；大腦把它拆成階段與工作，你寫的派工規則（例如「後端工作交給 Codex」）決定每個工作交給誰。工作流程頁有五個範本，也可以自訂階段。

Pyloxa 自己驗收。Agent 說做完了不算數。每個工作完成後，Pyloxa 會執行你核准的驗證命令，並檢查改動有沒有超出計畫的寫入範圍；每個階段結束時，還有一道 Gate 在合併後的版本上跑命令。另一家的 Agent 可以來測試，只能新增測試，以命令的結果為準（免費版由你按下才測，Pro 自動測試）。Conductor 的文件說明的是在合併前顯示 CI、狀態檢查與待辦，沒有說明由 App 自己執行你的測試命令來決定接不接受成果。

額度用完時換手。某個 CLI 額度用盡時，Pyloxa 不再派工給它，並依你的規則提出備援 Agent；你確認後，它從已經改好的檔案繼續。詳見額度與備援。

Conductor 有文件說明、Pyloxa 沒有的：Cursor 與 OpenCode、雲端工作區、手機 App、setup 與 run 腳本，以及在 diff 上逐行留言。Pyloxa 自己的限制：不開源、只有 Windows 版、安裝檔還沒有程式碼簽章（SmartScreen 可能會警告），結束 Pyloxa 時 Agent 也會停止。免費版同一時間只有一個專案在跑，用訂閱的 Claude Code 一次只接一個工作。

該選哪一個

  • 選 Conductor，如果你用 Mac；喜歡自己開每個 Agent，在同一個視窗看它的 diff、檢查與 PR；想用 Cursor、OpenCode、Bedrock 或 OpenRouter；或想要雲端工作區與 iPhone App。
  • 選 Pyloxa，如果你用 Windows 10 或 11；想把一個需求變成一份計畫，依規則分給 Claude Code 與 Codex；希望成果要通過你自己的命令才算數，並由另一家的 Agent 測試；而且希望某個 CLI 額度用完時，經你確認後換手。

可以兩個一起用嗎？

同一台電腦不行：Conductor 跑在 macOS，Pyloxa 跑在 Windows。如果你同時有 Mac 和 Windows 電腦，可以各自對同一個 GitHub repo 工作。兩邊都在自己的分支上做，成果在 pull request 會合。兩邊用同一個 Claude 或 ChatGPT 訂閱的話，會共用那個訂閱的用量上限。

常見問題

Conductor 有 Windows 版嗎？
截至 2026-11-19 沒有。Conductor 的安裝頁寫著它支援 macOS，目前還沒有 Windows 與 Linux 版，並提供登記，等推出時通知你。
Windows 上有什麼可以取代 Conductor？
Pyloxa 是其中一個：在 Windows 10 與 11 上執行的 App，讓 Claude Code 與 Codex CLI 各自在不同的 git worktree 裡工作。它不是 Conductor 的移植版，而是以計畫、派工規則與它自己跑的驗收為中心；它不支援 Cursor 與 OpenCode，也沒有雲端工作區。想在 Windows 上自己跑這些 CLI，請看Windows 跑 Claude Code、Codex 要裝 WSL 嗎？。
Conductor 能用 ChatGPT 訂閱跑 Codex 嗎？
可以。Codex 是內建的，從 0.89.0 起可以在 Settings → Agents → Codex 按 Continue with ChatGPT；原本的 codex login 或 API Key 也可以用。Pyloxa 執行 Codex CLI 時，用 codex login 或 OpenAI Platform 的 API Key。
Conductor 免費嗎？
App 免費，模型用量由你的服務商計費。它的 FAQ 說之後打算對協作功能收費。雲端工作區需要 Pro、Teams 或 Enterprise 方案，目前沒有另外收雲端費用。Pyloxa 的免費版會一直免費；Pro 每年 US$79，目前免費預覽中。
