簡短回答

Herdr 是免費、開源的 App，支援 macOS、Linux 與 Windows；每個 Coding Agent 都跑在真正的終端機裡，由本機的背景伺服器 herdr-core 維持執行，也能跑在你加入的 SSH 機器上。Pyloxa 是 Windows App：大腦負責規劃，每個工作依你的規則交給 Claude Code 或 Codex CLI，在各自的 git worktree 裡進行，Pyloxa 自己跑驗證，最後由你合併。想自己看著、操作每個 Agent，而且要跨機器，選 Herdr；想把一個需求變成有規劃、有驗收的派工，在一台 Windows 電腦上完成，選 Pyloxa。

Herdr 做得好的地方

  • Agent 比視窗活得久。App 負責畫終端機，herdr-core 負責執行。結束、更新 App，或 App 當掉，每個 Agent 都還在跑；用 hc attach 可以從你的 shell 接手任何一個終端機。重開機之後，窗格會在原本的資料夾開一個新的 shell，但 Agent 不會跟著回來。
  • 真正的終端機，什麼 Agent 都能跑。透過開放協定 OSC 7501 回報狀態的程式，會顯示為工作中、等你處理或已完成，側欄一看就知道哪個 Agent 在等你。
  • Agent 可以開 Agent。一個 Agent 能開幫手（hc run --bg codex "..."）、用 hc send 調整方向，並等子 Agent 做完。範本可以替幫手設定角色，例如唯讀的審查者。
  • 其他機器與手機。透過 SSH 加入伺服器、VM 或另一台筆電，那邊的 Agent 會出現在同一份清單。免費的手機 App 透過 SSH 回覆 Agent，不需要 Herdr 帳號。
  • 用說的就能改。版面、快捷鍵、主題與 JavaScript mod 都是 ~/.config/herdr-app 裡的檔案，你開口，Agent 就幫你改；herdr.dev 上也有別人分享的版面與 mod。

Pyloxa 的不同之處

Herdr 以終端機為主：每個 Agent 你都看得到，下一步做什麼由你決定。Pyloxa 則是接下一個需求，替你把協調的部分跑完。

  • 規劃與派工。大腦把需求拆成階段與工作，依工作類型的分工表把每個工作交給 Claude Code 或 Codex，例如後端工作交給 Codex。工作流程。
  • Pyloxa 自己跑驗證。每個工作完成後，Pyloxa 會執行你核准的測試、建置、lint 命令，並檢查改動的檔案有沒有超出計畫的寫入範圍。Agent 說「做完了」從來不算通過。也可以讓另一家廠商的 Agent 交叉測試，它只能新增測試。怎麼驗收 Agent 的成果。
  • 額度用盡時接手。標題列顯示每個 Agent 還剩多少額度。某個 CLI 額度用盡時，經你確認後，備援 Agent 從已經改好的檔案繼續（Pro 會自動接手）。額度與備援。
  • 由你合併。你決定之前，什麼都不會合併或推送；PR 說明裡可以附上驗證報告卡。

Herdr 有些事 Pyloxa 做不到：App 結束後仍讓 Agent 繼續跑的常駐程式、SSH 機器、手機 App、macOS 與 Linux，以及任何終端機程式都能當 Agent。Pyloxa 不開源，安裝檔目前還沒有程式碼簽章，第一次執行時 SmartScreen 可能會跳出警告。

該選哪一個

  • 選 Herdr，如果你用 macOS 或 Linux、想在各自的終端機裡自己操作每個 Agent、需要 App 關掉後 Agent 繼續跑、要跨 SSH 機器或用手機處理，或想要能自己改造的開源軟體。
  • 選 Pyloxa，如果你用 Windows，想把一個需求先規劃好、依你的規則分給 Claude Code 與 Codex、每個工作有自己的 worktree、每份成果都跑你自己的測試命令，最後由你合併。

可以兩個一起用嗎？

可以，在 64 位元 Windows 上都能裝，但兩者不會互通：Pyloxa 開的 Agent 不會出現在 Herdr 裡，Herdr 的 Agent 也不屬於 Pyloxa 的計畫。一種分法是：互動式的 Session 與遠端機器用 Herdr，需要規劃與驗收的工作用 Pyloxa。如果兩邊用的是同一組 CLI 登入，就會用到同一份訂閱額度；Claude Code 的額度也和 claude.ai 共用。

常見問題

Herdr 有 Windows 版嗎？
有，支援 x64 Windows（Windows 10 1803 以上），用一行 PowerShell 命令安裝。它也支援 Apple 晶片的 macOS，以及 x86-64 與 ARM64 的 Linux。Pyloxa 只支援 64 位元的 Windows 10 與 11。
Herdr 能跑 Claude Code 和 Codex 嗎？
可以，任何能在終端機執行的程式它都能跑。透過 OSC 7501 回報狀態的程式才會顯示狀態；不回報的程式就沒有狀態。
關掉 App 之後，Agent 還會繼續跑嗎？
Herdr 會，直到重開機為止。Pyloxa 在有工作時關閉視窗會留在系統匣；結束 Pyloxa 會停止它的 Agent，下次開啟時按「全部接續」可以繼續被中斷的工作。背景執行。
Pyloxa 能在遠端機器上跑 Agent 嗎？
不能。Pyloxa 只在安裝它的這台 Windows 電腦上執行 CLI。
兩個都免費嗎？
Herdr 以 Apache 2.0 免費提供。Pyloxa 免費版不需要帳號；Pro 每年 US$79，目前免費預覽。兩者都是用你自己的 CLI 訂閱或 API Key。
