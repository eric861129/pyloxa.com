Install in four steps

  1. Run the installerThe installer isn’t code-signed yet, so Windows may say it protected your PC. Choose “More info”, then “Run anyway”.
  2. Let the setup guide check your PCIt checks git, which is required, and Node.js, which is optional. If one is missing, it shows the winget command or the official download page. With Node.js, it installs Claude Code or Codex CLI with the official npm command after you confirm.
  3. Sign in to your agentsSign in to Claude Code or Codex with your own subscription, or add an API key. Pyloxa never reads, copies or sends your CLI sign-ins.
  4. Take the test driveBefore you open your own project, try Pyloxa on a small sample project with a hidden bug. The test drive needs Node.js and never touches your projects, pushes or opens a PR.

What you need

  • Windows 10 or 11, 64-bit
  • Git for Windows 2.30 or later
  • Claude Code or Codex CLI, signed in with your own subscription or using an API key. With both, Pyloxa can split the work and hand off when one runs out of quota.
  • Node.js 22 or later, only if you want the setup guide to install the CLIs for you, or to take the test drive

The free edition needs no account, and Pyloxa never sends your code or prompts to us.
