Télécharger Pyloxa pour Windows

Gratuit, sans compte. Pyloxa exécute les CLI Claude Code et Codex que vous utilisez déjà, avec vos propres abonnements ou clés d’API.

Le téléchargement a commencé. Si rien ne se passe, utilisez le bouton ci-dessous.

Télécharger le programme d’installation v0.2.0 · 130.5 MB · Windows 10 et 11, 64 bits

12 versions publiées depuis novembre 2026, chacune avec ses notes de version et sa somme SHA-256.

Installation en quatre étapes

  1. Lancez le programme d’installationLe programme d’installation n’est pas encore signé, donc Windows peut indiquer qu’il a protégé votre PC. Choisissez « Informations complémentaires », puis « Exécuter quand même ».
  2. Laissez l’assistant vérifier votre PCIl vérifie git (obligatoire) et Node.js (facultatif). S’il en manque un, il affiche la commande winget ou la page de téléchargement officielle. Avec Node.js, il installe Claude Code ou Codex CLI avec la commande npm officielle, après votre confirmation.
  3. Connectez-vous à vos agentsConnectez-vous à Claude Code ou à Codex avec votre propre abonnement, ou ajoutez une clé d’API. Pyloxa ne lit, ne copie et n’envoie jamais vos connexions aux CLI.
  4. Faites un essaiAvant d’ouvrir votre propre projet, essayez Pyloxa sur un petit projet d’exemple qui cache un bug. L’essai demande Node.js, ne touche jamais à vos projets, ne pousse rien et n’ouvre pas de PR.

Ce qu’il vous faut

  • Windows 10 ou 11, 64 bits
  • Git for Windows 2.30 ou version ultérieure
  • Claude Code ou Codex CLI, connecté avec votre propre abonnement ou une clé d’API. Avec les deux, Pyloxa peut répartir le travail et passer le relais quand l’un n’a plus de quota.
  • Node.js 22 ou version ultérieure, seulement si vous voulez que l’assistant installe les CLI pour vous, ou pour l’essai

L’édition gratuite ne demande aucun compte, et Pyloxa ne nous envoie jamais votre code ni vos prompts.
