Windows용 Pyloxa 다운로드

무료이며 계정이 필요 없습니다. Pyloxa는 이미 쓰고 있는 Claude Code와 Codex CLI를 내 구독이나 API 키로 실행합니다.

다운로드가 시작되었습니다. 시작되지 않으면 아래 버튼을 누르세요.

설치 파일 다운로드 v0.2.0 · 130.5 MB · Windows 10 및 11, 64비트

2026년 11월부터 12번 출시했고, 모든 버전에 릴리스 노트와 SHA-256 체크섬이 있습니다.

네 단계로 설치

  1. 설치 파일 실행설치 파일은 아직 코드 서명이 되어 있지 않아서 Windows가 PC를 보호했다고 표시할 수 있습니다. ‘추가 정보’를 누른 다음 ‘실행’을 누르세요.
  2. 설정 가이드로 PC 확인git(필수)과 Node.js(선택)를 확인합니다. 없으면 winget 명령이나 공식 다운로드 페이지를 알려 줍니다. Node.js가 있으면 확인을 받은 뒤 공식 npm 명령으로 Claude Code 또는 Codex CLI를 설치합니다.
  3. 에이전트에 로그인내 구독으로 Claude Code 또는 Codex에 로그인하거나 API 키를 추가하세요. Pyloxa는 CLI 로그인 정보를 읽거나 복사하거나 보내지 않습니다.
  4. 먼저 시승하기내 프로젝트를 열기 전에 버그를 숨겨 둔 작은 예제 프로젝트로 Pyloxa를 써 볼 수 있습니다. 시승에는 Node.js가 필요하며, 내 프로젝트는 건드리지 않고 푸시나 PR도 만들지 않습니다.

필요한 것

  • Windows 10 또는 11, 64비트
  • Git for Windows 2.30 이상
  • 내 구독으로 로그인했거나 API 키를 쓰는 Claude Code 또는 Codex CLI. 둘 다 있으면 Pyloxa가 일을 나누고, 한쪽 한도를 다 썼을 때 넘겨받게 할 수 있습니다.
  • Node.js 22 이상: 설정 가이드가 CLI를 설치하게 하거나 시승할 때만 필요합니다

무료 버전은 계정이 필요 없고, Pyloxa는 코드나 프롬프트를 우리에게 보내지 않습니다.

파일 확인(선택)

설치 파일이 바뀌지 않았는지 확인하려면, 다운로드한 폴더에서 PowerShell을 열고 아래 명령을 실행한 다음 결과를 아래 값과 비교하세요.

Get-FileHash .\Pyloxa-Setup-0.2.0.exe -Algorithm SHA256
