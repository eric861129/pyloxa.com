Download grátis

Baixar o Pyloxa para Windows

Grátis e sem conta. O Pyloxa roda as CLIs do Claude Code e do Codex que você já usa, com suas próprias assinaturas ou chaves de API.

O download começou. Se nada acontecer, use o botão abaixo.

Baixar o instalador v0.2.0 · 130.5 MB · Windows 10 e 11, 64 bits

12 versões lançadas desde novembro de 2026, cada uma com notas da versão e checksum SHA-256.

Instale em quatro passos

  1. Execute o instaladorO instalador ainda não tem assinatura de código, então o Windows pode dizer que protegeu seu PC. Escolha “Mais informações” e depois “Executar assim mesmo”.
  2. Deixe o assistente verificar seu PCEle verifica o git (obrigatório) e o Node.js (opcional). Se faltar algum, mostra o comando do winget ou a página oficial de download. Com o Node.js, instala o Claude Code ou o Codex CLI com o comando oficial do npm depois que você confirma.
  3. Entre nos seus agentesEntre no Claude Code ou no Codex com sua própria assinatura, ou adicione uma chave de API. O Pyloxa nunca lê, copia nem envia os logins das suas CLIs.
  4. Faça o test-driveAntes de abrir seu próprio projeto, experimente o Pyloxa num pequeno projeto de exemplo com um bug escondido. O test-drive precisa do Node.js, nunca mexe nos seus projetos, não faz push nem abre PR.

Do que você precisa

  • Windows 10 ou 11, 64 bits
  • Git for Windows 2.30 ou mais recente
  • Claude Code ou Codex CLI, com login na sua própria assinatura ou com uma chave de API. Com os dois, o Pyloxa divide o trabalho e passa a vez quando a cota de um acaba.
  • Node.js 22 ou mais recente, só se você quiser que o assistente instale as CLIs ou fazer o test-drive

A edição grátis não precisa de conta, e o Pyloxa nunca envia seu código nem seus prompts para nós.

Confira o arquivo (opcional)

Para garantir que o instalador não foi alterado, abra o PowerShell na pasta onde você o baixou, rode este comando e compare o resultado com o valor abaixo.

Get-FileHash .\Pyloxa-Setup-0.2.0.exe -Algorithm SHA256
