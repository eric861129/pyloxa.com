Pyloxa vs cmux

cmux gives you a programmable macOS terminal to run and watch many coding agents yourself. Pyloxa plans the work on Windows, sends each task to an agent by your rules, checks it with your commands and leaves the merge to you.

Updated November 19, 2026

Short answer

cmux, by Manaflow, is a free, open-source macOS terminal built on Ghostty for running many coding agents side by side, with notification rings, a scriptable browser pane and a CLI. Pyloxa is a Windows 10/11 app in which a brain agent plans the work, your rules send each task to Claude Code or Codex CLI in its own git worktree, and Pyloxa runs your checks before you merge. Pick cmux on a Mac if you want to drive any terminal agent yourself; pick Pyloxa on Windows if you want planning, checks and quota takeovers handled for you.

What cmux does well

  • Any agent, in real terminals. Every CLI agent works without an integration, and you see each session’s full output.
  • Knowing which agent needs you. A waiting agent’s pane gets a blue ring and its tab lights up. The sidebar shows each workspace’s git branch, linked pull request, ports and latest notification.
  • A browser beside the terminal. The browser pane can be scripted to click, fill forms, run JavaScript and read console and network activity, so an agent can check its own web changes.
  • Everything is scriptable. A CLI and a Unix socket create workspaces, split panes, send input and read the screen. Project actions go in cmux.json.
  • Remote work. cmux ssh opens a workspace on another machine; paid plans add Cloud VMs and an iOS app.
  • Open source and native. Built with Swift and AppKit, it reads your Ghostty config and costs nothing.

Where Pyloxa is different

cmux describes itself as building blocks you assemble. Pyloxa is one workflow whose steps you configure.

  • It plans and assigns. The brain splits a request into phases and tasks, and an assignment table decides which agent takes each type of task. See Workflow.
  • It checks the work itself. An agent saying it’s done doesn’t count. Pyloxa runs your test, build and lint commands, checks the plan’s write scope, and can have a second agent add tests. A finished plan gets a verification card for your PR. See Checks.
  • Quota takeovers. The title bar shows each agent’s remaining quota. When one runs out, another continues from the files already changed, after you confirm. See Quota & fallback.
  • You merge. Your working folder is never stashed or reset, and nothing is merged or pushed until you choose.

What Pyloxa doesn’t have: a terminal or browser pane, a documented CLI or socket API, or remote execution. It runs only Claude Code, Codex CLI and, experimentally, Gemini CLI. The free edition runs up to two tasks at a time, in one project at a time. Pyloxa is closed source, Windows only, and its installer isn’t code-signed, so SmartScreen may warn on first run. Quitting Pyloxa stops its agents.

Which one to choose

  • Choose cmux if you work on a Mac, want to steer agents yourself in real terminals, use agents beyond Claude Code and Codex, want a scriptable browser or SSH workspaces, or prefer open-source tools you can build on.
  • Choose Pyloxa if you work on Windows with Claude Code and Codex CLI and want a plan, rule-based assignment, separate worktrees, your own commands as the test of “done” and quota takeovers in one app, with the merge left to you.

Can you use both?

Not on one computer: cmux runs on macOS and Pyloxa on Windows. With a Mac and a Windows PC you can use each against the same repository. Pyloxa’s Sync to CLIs writes your project rules into AGENTS.md, which you can commit for the agents you run in cmux. See one instructions file for three CLIs.

FAQ

Is there cmux for Windows?
Not today. The cmux README says “macOS only, for now”, and the latest release has only macOS downloads. If you want a Windows app for running Claude Code and Codex on one project, Pyloxa is one option, though it works differently.
Does cmux run Claude Code and Codex?
Yes. cmux runs any agent that works in a terminal, and its README names both. It also has cmux claude-teams for Claude Code’s teammate mode and resume hooks for Codex and Claude Code.
Is cmux free? Is Pyloxa?
The cmux app is free and open source; its paid plans add Cloud VMs and the iOS app. Pyloxa’s free edition needs no account; Pro costs US$79 a year (early bird US$49) and is in a free preview until it goes on sale. Both run agents on your own subscriptions or API keys.
Does cmux create git worktrees?
Worktrees aren’t a listed feature, but the custom commands docs include an example, “Agents in New Worktree”, that creates one and opens Codex and Claude Code in it. Pyloxa creates a worktree for every task.
