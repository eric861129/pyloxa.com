Pyloxa vs Herdr

Herdr gives your coding agents real terminals that keep running and lets you steer each one yourself. Pyloxa sits above the terminals: it plans the work, routes it by your rules and checks the results before you merge.

Updated November 19, 2026

Short answer

Herdr is a free, open-source app for macOS, Linux and Windows where each coding agent runs in a real terminal kept alive by a local server, herdr-core, including on SSH machines you add. Pyloxa is a Windows app where a brain agent plans the work, each task goes to Claude Code or Codex CLI by your rules in its own git worktree, and Pyloxa runs your checks before you merge. Pick Herdr to watch and steer each agent yourself, across machines; pick Pyloxa to turn one request into a planned, checked run on one Windows PC.

What Herdr does well

  • Agents outlive the window. The app draws terminals; herdr-core runs them. Quitting, updating or crashing the app leaves every agent running, and hc attach takes over any terminal from your shell. After a reboot, panes come back with a fresh shell in the same folder, without the agent.
  • Real terminals, any agent. Programs that report status through OSC 7501, an open protocol, show as working, blocked or done, so the sidebar shows which agent needs you.
  • Agents run agents. An agent starts a helper (hc run --bg codex "..."), steers it with hc send and waits for its children. Templates give a helper a role, such as a read-only reviewer.
  • Other machines and your phone. Add a server, VM or laptop over SSH and its agents join the same list. The free phone app answers agents over SSH, with no Herdr account.
  • Shaped by asking. Layouts, keys, themes and JavaScript mods are files in ~/.config/herdr-app that your agent edits on request, with shared layouts and mods on herdr.dev.

Where Pyloxa is different

Herdr is terminal-first: you see every agent and decide what each does next. Pyloxa takes one request and runs the coordination for you.

  • Planning and routing. A brain agent splits the request into phases and tasks, and an assignment table by task type sends each to Claude Code or Codex, for example backend tasks to Codex. Workflow.
  • Checks Pyloxa runs itself. After each task Pyloxa runs the test, build and lint commands you approved and checks the changed files against the plan’s write scope. An agent saying “done” never counts as passing. An agent from another vendor can cross-test, adding tests only. Checking an agent’s work.
  • Quota takeovers. The title bar shows each agent’s remaining quota. When a CLI runs out, the fallback agent continues from the files already changed after you confirm (automatic in Pro). Quota and fallback.
  • You merge. Nothing is merged or pushed until you choose, and a verification card can go into the PR description.

Herdr does things Pyloxa doesn’t: a daemon that keeps agents running after the app quits, SSH machines, a phone app, macOS and Linux, and any terminal program as an agent. Pyloxa is closed source, and its installer is not code-signed yet, so SmartScreen may warn on first run.

Which one to choose

  • Choose Herdr if you’re on macOS or Linux, want to steer each agent in its own terminal, need agents to keep running when the app closes, work across SSH machines or from your phone, or want open-source software you can reshape.
  • Choose Pyloxa if you’re on Windows and want one request planned, split between Claude Code and Codex by your rules, each task in its own worktree, your own test commands run on every result, and the merge left to you.

Can you use both?

Yes, on 64-bit Windows, but they don’t connect: agents Pyloxa starts don’t appear in Herdr, and Herdr’s agents aren’t part of a Pyloxa plan. One split is Herdr for interactive sessions and remote machines, Pyloxa for a planned job with checks. If both use the same CLI sign-ins, they draw on the same subscription quota; Claude Code’s is also shared with claude.ai.

FAQ

Does Herdr run on Windows?
Yes, on x64 Windows (Windows 10 1803 or newer), installed with a PowerShell command. It also runs on macOS with Apple silicon and on Linux x86-64 and ARM64. Pyloxa runs on 64-bit Windows 10 and 11 only.
Does Herdr run Claude Code and Codex?
Yes, it runs anything that runs in a terminal. Status appears for programs that report it through OSC 7501; a program that reports nothing shows no status.
Do agents keep running when I close the app?
In Herdr, yes, until a reboot. In Pyloxa, closing the window while work runs keeps it in the tray; quitting stops its agents, and Resume All continues interrupted tasks next time. Background running.
Can Pyloxa run agents on a remote machine?
No. Pyloxa runs the CLIs on the Windows PC where it is installed.
Are they free?
Herdr is free under Apache 2.0. Pyloxa’s free edition needs no account; Pro is US$79 a year and in a free preview now. Both run the CLIs on your own subscriptions or API keys.
