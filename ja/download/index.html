無料ダウンロード

Windows 版 Pyloxa をダウンロード

無料で、アカウントも不要です。Pyloxa は、すでに使っている Claude Code と Codex CLI を、あなた自身のサブスクリプションまたは API キーで実行します。

ダウンロードを開始しました。始まらない場合は、下のボタンを使ってください。

インストーラーをダウンロード v0.2.0 · 130.5 MB · Windows 10 / 11（64 ビット）

2026 年 11 月から 12 回リリースし、すべてにリリースノートと SHA-256 チェックサムがあります。

4 ステップでインストール

  1. インストーラーを実行インストーラーはまだコード署名されていないため、「Windows によって PC が保護されました」と表示されることがあります。「詳細情報」を選び、「実行」を選んでください。
  2. セットアップガイドで PC を確認git（必須）と Node.js（任意）を確認します。足りない場合は winget コマンドか公式のダウンロードページを示します。Node.js があれば、確認のうえで公式の npm コマンドを使って Claude Code または Codex CLI をインストールします。
  3. エージェントにサインイン自分のサブスクリプションで Claude Code または Codex にサインインするか、API キーを追加します。Pyloxa が CLI のサインイン情報を読み取ったり、コピーしたり、送信したりすることはありません。
  4. まずは試乗自分のプロジェクトを開く前に、バグを仕込んだ小さなサンプルプロジェクトで Pyloxa を試せます。試乗には Node.js が必要です。あなたのプロジェクトには触れず、プッシュや PR の作成もしません。

必要なもの

  • Windows 10 または 11（64 ビット）
  • Git for Windows 2.30 以降
  • Claude Code または Codex CLI（自分のサブスクリプションでサインインするか、API キーを使用）。両方あると、Pyloxa が作業を分担し、どちらかの利用枠が尽きたときに引き継げます。
  • Node.js 22 以降：セットアップガイドに CLI をインストールさせる場合と、試乗する場合だけ必要です

無料版はアカウント不要で、Pyloxa があなたのコードやプロンプトを私たちに送ることはありません。

ファイルの確認（任意）

インストーラーが改ざんされていないか確かめるには、ダウンロードしたフォルダーで PowerShell を開き、次のコマンドを実行して、下の値と比べてください。

Get-FileHash .\Pyloxa-Setup-0.2.0.exe -Algorithm SHA256

SHA-2560ba00a15f5f16be60c2d1b453e622abd3f4895bf5e1e2045aac9fc52734f35af
