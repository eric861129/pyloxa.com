隱私權政策

這份政策適用於 pyloxa.com 官網、Pyloxa 桌面 App 與 account.pyloxa.com 的 Pyloxa 帳號服務。免費版的 App 不需要帳號，不會把你的專案、程式碼或提示內容傳給我們；只有在你開啟匿名使用統計時才會傳送使用資料，預設是關閉的。你為了試用、Pro 預覽或 Pro 登入時，帳號只用來授權。官網只統計瀏覽情形，你加入 Pro 早鳥名單時才會留下 email。

Pyloxa 由台灣的個人開發者 ChiYu-Huang（下稱「我們」）製作，也由我們決定這裡所說的個人資料怎麼使用。對這份政策有任何問題，請寫信到 support@pyloxa.com。

官網

網站主機與字型

pyloxa.com 架在 GitHub Pages。你開啟網頁時，GitHub 會收到你的 IP 位址，並為了安全目的記錄下來，所有 GitHub Pages 網站的訪客都是如此。網站的字型由 pyloxa.com 自己提供，不會有字型服務收到你的 IP 位址。網域的 DNS 查詢由 Cloudflare 回應。

瀏覽統計

  • Cloudflare Web Analytics：每一頁都有。統計瀏覽次數、從哪些網站連過來、國家、瀏覽器類型與網頁載入速度。不使用 cookie 或本機儲存空間，也不會辨識個別訪客的裝置。
  • Google Analytics 4：首頁與「找不到網頁」頁面有，但只對歐洲以外的訪客載入（見下方）。記錄瀏覽、下載連結的點擊，以及早鳥表單送出了一次（不含你填的 email）。廣告功能與 Google 信號都已關閉。Google 表示 Google Analytics 4 不會記錄或儲存 IP 位址。事件層級的資料最多保留 14 個月，我們只看得到彙總後的報表。
  • 歐洲的訪客：載入 Google Analytics 之前，網頁會先讀取你裝置的時區。時區在歐洲（涵蓋歐洲經濟區、英國與瑞士）或它們的海外地區、是 UTC，或讀不到時，網頁完全不載入 Google Analytics，Google 也不會從這裡收到任何資料，只有 Cloudflare Web Analytics 統計你的瀏覽。
  • Cookie：其他地區的訪客，Google Analytics 會設定 _ga 與 _ga_PWKKJHQV92 兩個 cookie，最長保存兩年，用來區分新訪客與回訪的訪客。如果 Google 仍判斷你在歐洲經濟區、英國或瑞士，就不會設定 cookie。你可以在瀏覽器封鎖這些 cookie，或安裝 Google 的 Google Analytics 停用外掛程式。

Pro 早鳥名單

你在「通知我」表單輸入 email 時，email 會直接送到我們寄信用的 Buttondown。Buttondown 會先寄一封確認信，你確認之後才會加入名單。

  • 保存哪些資料：你的 email、標示你加入 Pro 早鳥名單與使用哪個語言頁面的標籤，以及加入的時間。Buttondown 另外會記錄 IP 位址、瀏覽器與大略位置等技術資料，詳見它的隱私權政策。
  • 用途：Pro 推出時寄一封信，附上早鳥優惠。我們不會把你加進其他名單，也不會把 email 提供給其他人。
  • 保存期間：到你取消訂閱或要求刪除為止。每封信都有取消訂閱的連結。取消訂閱後，Buttondown 會保留一筆紀錄，避免再寄信給你；想完全刪除，請寫信給我們。
  • 加入名單是自願的。不留 email 只是收不到推出通知；下載與使用免費版都不需要 email 或帳號。早鳥名單和 Pro 帳號是分開的，登入不會讓你加入名單。

Pyloxa App

免費版不需要帳號

免費版不需要帳號，也不會連到我們的帳號服務。Pyloxa 不會傳給我們任何當機回報、專案檔案、提示內容或憑證；除非你開啟匿名使用統計，否則也不會傳送使用資料。「設定」裡顯示的統計是在你的電腦計算的。

Pro 的帳號（試用、Pro 預覽與 Pro）

試用、Pro 預覽與 Pro 需要登入。帳號只用來授權：不和匿名使用統計關聯，也不用來寄行銷信。登入時會用你的瀏覽器開啟我們的帳號服務 account.pyloxa.com，它在 Cloudflare Workers 上執行，資料存在 Cloudflare 亞太區的 D1 資料庫。

  • 登入方式：Google、GitHub，或寄到你 email 的 6 位數驗證碼。從 Google 我們只取得已驗證的 email 與 Google 帳號 ID（範圍 openid 與 email）；從 GitHub 只取得已驗證的主要 email 與 GitHub 使用者 ID（read:user、user:email）。我們不保存 Google 或 GitHub 的 access token。驗證碼經由 Resend 寄出。
  • 保存哪些資料：
    • 你的 email 與連結的登入方式，保存到帳號刪除為止。
    • 你登入的每台電腦：Pyloxa 產生的隨機裝置 ID（不是硬體指紋）、預設為電腦名稱而且可以改的名稱、最後一次更新授權的時間，以及 Pyloxa 與 Windows 的版本。保存到你移除這台電腦或刪除帳號為止。
    • 你的授權、試用或 Pro 預覽，以及 Polar 的訂單、訂閱與客戶 ID 和購買時用的 email，保存到帳號刪除為止。
    • 登入、電腦異動與簽發授權的安全紀錄，含請求的 IP 位址，保存 13 個月。頻率限制會用到 IP 位址，最多保留兩天。
  • 每天更新授權：登入之後，Pyloxa 在啟動時與大約每天一次更新授權，只把裝置 ID、裝置憑證與 Pyloxa、Windows 的版本送到 account.pyloxa.com。連不上時，Pro 從最後一次更新起還可以用 14 天。
  • 付款：購買 Pro 時會開啟 Polar 的結帳頁。Polar 是代理銷售商（merchant of record），依它自己的隱私權政策處理付款、稅務、發票與退款。我們會把帳號的 email 與隨機的帳號 ID 交給 Polar，讓這筆購買對應到你。我們看不到你的卡號。
  • 我們寄的信：驗證碼、試用到期提醒，以及和授權有關的服務通知（例如 Pro 預覽結束），都經由 Resend 寄出。我們不會寄行銷信給帳號。
  • Pro 預覽：Pro 開賣之前，登入就能免費使用 Pro。預覽在開賣時結束，至少提前 30 天在 App 與 email 通知。之後你還有 14 天的 Pro，並在 App 與帳號頁看到早鳥折扣；之後 App 回到免費版，資料與設定都保留。
  • 帳號頁（account.pyloxa.com/account）列出你的電腦與授權，可以改電腦名稱、移除電腦、下載你的資料（JSON）與刪除帳號。它使用兩個登入必要的 cookie：登入過程中的 pyloxa_signin，以及讓你在帳號頁保持登入 7 天的 pyloxa_account。帳號頁不載入任何分析程式或第三方內容。
  • 刪除帳號會刪除登入方式、電腦、授權、帳號頁的登入狀態與安全紀錄，並把 email 換成無法聯絡的佔位。每個裝置 ID 用過試用的紀錄會保留，不含個人資料，以免重複試用。Polar 依它的規定與稅法保留訂單與發票。

匿名使用統計（選擇加入）

Pyloxa 可以每天傳給我們一份匿名報告，讓我們知道有多少人持續使用、新使用者卡在哪一步，以及哪個 Agent 最常失敗。這個功能預設關閉。Pyloxa 會在你第一次接受工作成果後詢問一次，之後隨時可以在「設定 → 使用統計與回報」開啟或關閉。在同一頁也能先看到會送出的完整報告。

  • 報告的內容：開啟分享時產生的隨機匿名 ID 與日期，另外還有：
    • Pyloxa 的版本、從 GitHub 或 Microsoft Store 取得、Windows 10 或 11、介面語言。
    • 版本類型（免費、試用或 Pro）、第一次使用的週次，以及有沒有走完設定精靈。
    • 每個 CLI 有沒有安裝與登入、主次版號，以及用訂閱還是 API Key。
    • 當天的次數：對話、大腦的回覆、計畫、工作與結果類別（例如完成、額度用盡、限流）、接受成果的方式、備援接手、交叉測試、大腦驗收與背景執行。
    • 功能設定：大腦驗收、交叉測試、精簡回覆、worktree 的使用方式、關閉視窗時的行為，以及是否防止電腦睡眠。
  • 絕對不包含：提示內容、指示、程式碼、檔名、路徑、專案或 repo 名稱、CLI 的輸出、錯誤訊息、帳號名稱、email 或 API Key。匿名 ID 不會和 Pro 帳號關聯。
  • 送到哪裡：我們在 stats.pyloxa.com 的接收端，在 Cloudflare 上執行。我們不保存你的 IP 位址或瀏覽器資訊，只保存 Cloudflare 從 IP 判斷的國家代碼（兩個字母）。App 裡沒有任何第三方的分析程式。
  • 保存多久：報告保存 13 個月，之後只保留沒有 ID 的每天總數。連不上網路時，還沒送出的報告會在你的電腦上保留最多 7 天。
  • 你可以怎麼做：
    • 關閉分享會停止傳送，並刪除電腦上的匿名 ID 與還沒送出的報告。
    • 「刪除我的資料」會請接收端刪除這個 ID 的所有報告，然後關閉分享。
    • 「重設匿名 ID」會換一個新的 ID 重新開始。

Pyloxa 自己發出的網路請求

  • 查詢新版本：啟動時和每 12 小時，Pyloxa 會向 GitHub（api.github.com）查詢 Pyloxa 的最新版本與 CLI 相容性目錄。和所有網路請求一樣，GitHub 會看到你的 IP 位址；請求裡另外帶著 Pyloxa 的版本號碼，但沒有任何專案或使用資料。可以在「設定 → 通知與更新」關閉。
  • Pro 的登入與授權更新：只在你登入之後。登入時用瀏覽器開啟 account.pyloxa.com；之後依上面的說明大約每天更新一次授權。免費版不會連線。
  • 通知（Pro）：只在你設定之後，Pyloxa 會把專案名稱、事件（例如等你處理、Gate 沒通過、計畫完成、額度用盡）與計畫或工作的標題，從你的電腦直接送到你指定的 Telegram bot、Discord webhook 或 HTTPS webhook，適用這些服務的條款，訊息不經過我們。bot token 與 webhook 網址以 Windows 的安全儲存加密。
  • 匿名使用統計：只在你開啟時，Pyloxa 開著的期間大約每小時把整理好的每天報告送到 stats.pyloxa.com（見上方說明）。
  • 安裝或更新 CLI：只有在你按下並確認後，Pyloxa 才會執行官方的安裝命令，從 npm 或 CLI 的供應商下載。
  • Git 與 GitHub：fetch、pull、push 與建立 PR 都只在你選擇時進行，使用你自己的 git 遠端與 GitHub CLI 登入。
  • 在你電腦上的 Agent 工具：Pyloxa 開著的期間，會在 127.0.0.1 的隨機埠等候連線，讓它啟動的 Agent 搜尋與提議共用記憶。其他電腦連不上，也不會透過網際網路傳送任何內容。
  • 不下載拼字檢查字典：拼字檢查已關閉，Pyloxa 不會下載字典。0.1.0 到 0.1.8 第一次啟動時會從 Google（redirector.gvt1.com）下載英文拼字檢查字典，這一頁之前沒有列出。這項請求會讓 Google 知道你的 IP 位址，不含其他資料。已經下載的字典留在 %APPDATA%\Pyloxa\Dictionaries，可以直接刪除這個資料夾。
  • App 裡的連結（例如改版紀錄）會在你的瀏覽器開啟，適用上面「官網」的說明。

AI Agent

Pyloxa 在你的電腦上執行 Claude Code、Codex CLI 與 Gemini CLI。這些工具會以你自己的帳號或 API Key，把提示內容、程式碼與它們讀到的檔案送給 Anthropic、OpenAI 與 Google，適用這些供應商的條款與隱私權政策；我們不會收到這些內容。Pyloxa 不會讀取、複製或傳送 CLI 的登入憑證。執行 Gemini CLI 時，Pyloxa 使用一個獨立的設定資料夾，並在其中關閉 Gemini CLI 的使用統計。你在 Pyloxa 共用記憶裡保存的記憶，會帶進你使用的每個 Agent 的 prompt，所以會送到這些供應商。

存在你電腦上的資料

  • %APPDATA%\Pyloxa：開過的專案、對話、計畫、工作紀錄與執行記錄、共用記憶、設定與使用統計。開啟匿名使用統計時，另外存著匿名 ID 與還沒送出的報告。
  • 你設定的 API Key 以 Windows 的安全儲存加密，存在同一個資料夾。Pyloxa 只把 Key 交給執行該工作的 CLI 程序。
  • 登入之後，授權、裝置 ID 與裝置憑證以 Windows 的安全儲存加密，存在同一個資料夾。登入期間，帳號的 email 也存在這個資料夾，讓設定頁顯示。登出會從這台電腦刪除授權、憑證與 email。
  • %LOCALAPPDATA%\Pyloxa\worktrees：Agent 工作用的 git worktree。
  • 只有你選擇時才會寫入：「同步到各 CLI」會把專案的規則與偏好寫進該專案的 AGENTS.md 與相關檔案；使用者層的選項會把規則與偏好寫進 ~/.claude/CLAUDE.md、~/.codex/AGENTS.md 與 ~/.gemini/GEMINI.md 裡標示好的區塊，並先把原本的檔案備份到 %APPDATA%\Pyloxa\memory-backup。各 CLI 在你使用時，會把這些檔案的內容送給它們的供應商。
  • 解除安裝 Pyloxa 時會保留這些資料夾，以免你的紀錄不見。要全部移除，請在解除安裝後刪除這兩個資料夾，再到你的專案執行 git worktree prune。

診斷資訊與問題回報

「設定 → 使用統計與回報 → 複製診斷資訊」只會把 Pyloxa、Windows 與 CLI 的版本複製到剪貼簿，不會傳送任何東西。GitHub 上的 issue 是公開的，適用 GitHub 的隱私權聲明，請勿貼上 API Key、token 或不能公開的程式碼。

法律依據

如果你在歐洲經濟區、英國或瑞士，我們依據的是：

  • 你的同意：早鳥名單，你確認 email 時同意。隨時可以取消訂閱來撤回同意。
  • 你的同意：App 的匿名使用統計，你開啟時同意。隨時可以關閉來撤回同意；「刪除我的資料」會刪除已經送出的報告。
  • 履行和你的契約：帳號、登入、授權與付款的紀錄，是提供試用、Pro 預覽與 Pro 所必需。
  • 我們的正當利益：安全紀錄與頻率限制，用於維護帳號安全，並防止一份授權超出上限共用。
  • 我們的正當利益：網站主機記錄與 Cloudflare 不使用 cookie 的瀏覽統計，用於維護網站安全，並了解有多少人瀏覽與下載 Pyloxa。裝置時區在歐洲時，網頁不會載入 Google Analytics。

你的權利

依台灣的個人資料保護法，你可以請我們告訴你保存了你的哪些個人資料、提供複本、補充或更正、停止蒐集、處理或利用，或刪除。歐洲經濟區、英國與瑞士的訪客另依 GDPR，可以反對我們處理你的資料、以可攜的格式取得你的資料，也可以向當地的資料保護機關申訴。

請寫信到 support@pyloxa.com。與早鳥名單有關的要求，請用那個 email 寄出，方便我們找到。Pro 帳號可以在帳號頁自己下載資料與刪除帳號，也可以用帳號的 email 寫信給我們。與使用統計有關的要求，請在 App 按「刪除我的資料」，或把「設定 → 使用統計與回報」顯示的匿名 ID 寄給我們；沒有這個 ID，我們無法分辨哪些報告是你的。我們會在 15 天內回覆，30 天內處理完成。我們看到的瀏覽統計是彙總後的數字，不會連到你的姓名或 email，所以通常無法找出單一訪客的紀錄。

兒童、安全與政策變更

  • 官網與 App 不是為兒童設計的。未滿 16 歲請不要加入早鳥名單。
  • 官網與帳號服務只透過 HTTPS 提供。早鳥名單與帳號資料庫只有我們能存取。驗證碼、授權碼與裝置憑證只存雜湊。
  • 蒐集的資料有變動時，我們會在變動生效前更新這一頁與上方的日期。這一頁過去的版本都在官網公開的 GitHub repo。
  • 這份政策另有英文版；兩者不一致時，以英文版為準。
