隱私權政策

這份政策適用於 pyloxa.com 官網與 Pyloxa 桌面 App（免費版）。App 沒有伺服器，不會把你的專案內容傳給我們；官網只統計瀏覽情形，你加入 Pro 早鳥名單時才會留下 email。

最後更新：2026 年 11 月 6 日

我們是誰

Pyloxa 由台灣的個人開發者 ChiYu-Huang（下稱「我們」）製作，也由我們決定這裡所說的個人資料怎麼使用。對這份政策有任何問題，請寫信到 support@pyloxa.com。

官網

網站主機與字型

pyloxa.com 架在 GitHub Pages。你開啟網頁時，GitHub 會收到你的 IP 位址，並為了安全目的記錄下來，所有 GitHub Pages 網站的訪客都是如此。網站的字型從 Google Fonts 載入，所以 Google 傳送字型時也會收到你的 IP 位址與瀏覽器資訊，這個過程不使用 cookie。網域的 DNS 查詢由 Cloudflare 回應。

瀏覽統計

  • Cloudflare Web Analytics：每一頁都有。統計瀏覽次數、從哪些網站連過來、國家、瀏覽器類型與網頁載入速度。不使用 cookie 或本機儲存空間，也不會辨識個別訪客的裝置。
  • Google Analytics 4：首頁與「找不到網頁」頁面有。記錄瀏覽、下載連結的點擊，以及早鳥表單送出了一次（不含你填的 email）。廣告功能與 Google 信號都已關閉。Google 表示 Google Analytics 4 不會記錄或儲存 IP 位址。事件層級的資料最多保留 14 個月，我們只看得到彙總後的報表。
  • Cookie：在歐洲經濟區、英國與瑞士以外，Google Analytics 會設定 _ga 與 _ga_PWKKJHQV92 兩個 cookie，最長保存兩年，用來區分新訪客與回訪的訪客。歐洲經濟區、英國與瑞士的訪客不會被設定 cookie，Google Analytics 只送出不含 cookie 的統計。你可以在瀏覽器封鎖這些 cookie，或安裝 Google 的 Google Analytics 停用外掛程式。

Pro 早鳥名單

你在「通知我」表單輸入 email 時，email 會直接送到我們寄信用的 Buttondown。Buttondown 會先寄一封確認信，你確認之後才會加入名單。

  • 保存哪些資料：你的 email、標示你加入 Pro 早鳥名單與使用哪個語言頁面的標籤，以及加入的時間。Buttondown 另外會記錄 IP 位址、瀏覽器與大略位置等技術資料，詳見它的隱私權政策。
  • 用途：Pro 推出時寄一封信，附上早鳥優惠。我們不會把你加進其他名單，也不會把 email 提供給其他人。
  • 保存期間：到你取消訂閱或要求刪除為止。每封信都有取消訂閱的連結。取消訂閱後，Buttondown 會保留一筆紀錄，避免再寄信給你；想完全刪除，請寫信給我們。
  • 加入名單是自願的。不留 email 只是收不到推出通知；下載與使用 Pyloxa 都不需要 email 或帳號。

Pyloxa App

不需要帳號，不收集使用資料

Pyloxa 不需要帳號，也沒有自己的伺服器。它不會傳給我們任何使用資料、當機回報、專案檔案、提示內容或憑證。「設定」裡的使用統計只在你的電腦計算，不會傳送。

Pyloxa 自己發出的網路請求

  • 查詢新版本：啟動時和每 12 小時，Pyloxa 會向 GitHub（api.github.com）查詢 Pyloxa 的最新版本與 CLI 相容性目錄。和所有網路請求一樣，GitHub 會看到你的 IP 位址；請求裡另外帶著 Pyloxa 的版本號碼，但沒有任何專案或使用資料。可以在「設定 → 通知與更新」關閉。
  • 安裝或更新 CLI：只有在你按下並確認後，Pyloxa 才會執行官方的安裝命令，從 npm 或 CLI 的供應商下載。
  • Git 與 GitHub：fetch、pull、push 與建立 PR 都只在你選擇時進行，使用你自己的 git 遠端與 GitHub CLI 登入。
  • App 裡的連結（例如改版紀錄）會在你的瀏覽器開啟，適用上面「官網」的說明。

AI Agent

Pyloxa 在你的電腦上執行 Claude Code、Codex CLI 與 Gemini CLI。這些工具會以你自己的帳號或 API Key，把提示內容、程式碼與它們讀到的檔案送給 Anthropic、OpenAI 與 Google，適用這些供應商的條款與隱私權政策；我們不會收到這些內容。Pyloxa 不會讀取、複製或傳送 CLI 的登入憑證。執行 Gemini CLI 時，Pyloxa 使用一個獨立的設定資料夾，並在其中關閉 Gemini CLI 的使用統計。

存在你電腦上的資料

  • %APPDATA%\Pyloxa：開過的專案、對話、計畫、工作紀錄與執行記錄、設定與使用統計。
  • 你設定的 API Key 以 Windows 的安全儲存加密，存在同一個資料夾。Pyloxa 只把 Key 交給執行該工作的 CLI 程序。
  • %LOCALAPPDATA%\Pyloxa\worktrees：Agent 工作用的 git worktree。
  • 解除安裝 Pyloxa 時會保留這些資料夾，以免你的紀錄不見。要全部移除，請在解除安裝後刪除這兩個資料夾，再到你的專案執行 git worktree prune。

診斷資訊與問題回報

「設定 → 使用統計與回報 → 複製診斷資訊」只會把 Pyloxa、Windows 與 CLI 的版本複製到剪貼簿，不會傳送任何東西。GitHub 上的 issue 是公開的，適用 GitHub 的隱私權聲明，請勿貼上 API Key、token 或不能公開的程式碼。

法律依據

如果你在歐洲經濟區、英國或瑞士，我們依據的是：

  • 你的同意：早鳥名單，你確認 email 時同意。隨時可以取消訂閱來撤回同意。
  • 我們的正當利益：網站主機記錄、字型與瀏覽統計，用於維護網站安全，並了解有多少人瀏覽與下載 Pyloxa。在你所在的地區，這些統計不使用 cookie。

你的權利

依台灣的個人資料保護法，你可以請我們告訴你保存了你的哪些個人資料、提供複本、補充或更正、停止蒐集、處理或利用，或刪除。歐洲經濟區、英國與瑞士的訪客另依 GDPR，可以反對我們處理你的資料、以可攜的格式取得你的資料，也可以向當地的資料保護機關申訴。

請寫信到 support@pyloxa.com。與早鳥名單有關的要求，請用那個 email 寄出，方便我們找到。我們會在 15 天內回覆，30 天內處理完成。我們看到的瀏覽統計是彙總後的數字，不會連到你的姓名或 email，所以通常無法找出單一訪客的紀錄。

兒童、安全與政策變更

  • 官網與 App 不是為兒童設計的。未滿 16 歲請不要加入早鳥名單。
  • 官網只透過 HTTPS 提供。早鳥名單只有我們能存取。
  • 蒐集的資料有變動時，我們會在變動生效前更新這一頁與上方的日期。已經規劃、開始前會先寫進這裡的有：Pro 的登入與付款（由擔任代理銷售商的金流服務處理，我們看不到你的卡號），以及 App 裡經你同意才會傳送的使用統計。這一頁過去的版本都在官網公開的 GitHub repo。
