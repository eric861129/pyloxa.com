Pro

免費版陪你做一個專案，Pro 幫你顧好所有專案

免費版就能走完整個流程：擬計畫、派工、驗收、合併。Pro 把你原本要親手做的事交給 Pyloxa：多個專案一起跑、在你設定的範圍內自己決定、額度用完自己接手、做完自己找另一個 Agent 測試。現在登入就能免費預覽。

  • 2 台每個授權可以使用的電腦

  • 永久停止續訂後，訂閱期間發布的版本仍可使用 Pro

Pro 預覽：登入就能免費用

從 0.1.10 起，在 App 裡登入就能使用所有 Pro 功能，不需要信用卡。

  • 可以用 Google、GitHub 或寄到信箱的驗證碼登入。
  • 預覽一直免費到 Pro 開賣，結束日至少提前 30 天通知。
  • 開賣後還有 14 天的 Pro；之後回到免費版，資料與設定都會保留。
  • 預覽期間還不能購買，App 裡也沒有購買按鈕。

帳號只用來授權

免費版不需要帳號，也不會連到授權服務。登入 Pro 預覽或 Pro 之後，帳號只用來發授權。

  • 大約每天更新一次授權，只送裝置 ID、App 與 Windows 的版本。專案、程式碼與提示內容都不會傳給我們。
  • 每個授權可以用在 2 台電腦。第 3 台登入時，會請你先移除一台；每 30 天最多移除 3 次。
  • 網路不通、更新不了的話，從上次成功更新起還有 14 天的 Pro，第 3 天開始提醒你。
  • 詳細內容見隱私權政策。

回到免費版時，什麼都不會刪

Pro 結束時，正在執行的工作會做完，設定全部保留、暫停，回到 Pro 時再恢復。App 會一次列出受影響的設定，並在原本的位置標示「需要 Pro，已暫停」。

  • 多個專案：留一個專案繼續執行，其他的等待。
  • 授權範圍內自動：新的計畫改為建議後詢問，已核准的計畫照常執行。
  • 自動備援：改回每次由你確認。
  • 我的流程：全部保留，專案暫時照全域設定。
  • 排定時間的計畫：保留，但不會自己開始，你可以手動開始。
  • 用量儀表板：鎖起來，但用量照常記錄。
  • Skills 庫：各 CLI 照樣讀得到，只是不能再修改。已匯入的派工包照常生效。
  • 停止續訂（不是預覽結束）時，訂閱期間發布的版本仍可永久使用 Pro。

免費版會一直免費

安全與正確性相關的功能都在免費版：不碰 CLI 憑證、獨立的 worktree、寫入範圍、驗證命令、階段 Gate，以及「沒驗證過的不會標成通過」。免費與 Pro 的劃分在預覽開始前就定好了，已經免費的功能不會改成 Pro。

常見問題

Pro 預覽什麼時候結束？

Pro 開賣時結束，日期至少提前 30 天通知。開賣後還有 14 天的 Pro，之後回到免費版，資料與設定都會保留。

Pro 多少錢？早鳥價怎麼算？

Pro 每年 US$79。早鳥價每年 US$49，早鳥登記即將開放；只要持續訂閱，每年都是這個價格。預覽期間還不能購買。

停止續訂後，Pro 功能會消失嗎？

訂閱期間發布的版本，停止續訂後仍可永久使用 Pro 功能；之後發布的新版本會回到免費版的功能。Pro 預覽不適用這一點。

一個授權可以裝幾台電腦？

2 台。第 3 台登入時，會請你先移除一台；每 30 天最多移除 3 次。

登入後，Pyloxa 會收集我的程式碼嗎？

不會。帳號只用來授權，大約每天更新一次授權，只送裝置 ID、App 與 Windows 的版本。你的程式碼與提示內容只會送到 CLI 原本會送去的地方。
