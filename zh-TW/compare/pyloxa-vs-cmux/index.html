Pyloxa vs cmux

cmux 給你一個可程式化的 macOS 終端機，自己開、自己盯很多個 Coding Agent。Pyloxa 在 Windows 上替你規劃工作、依你的規則派工、用你的命令驗收，合併由你決定。

更新於 2026 年 11 月 19 日

簡短回答

cmux 是 Manaflow 做的免費開源 macOS 終端機，以 Ghostty 為基礎，讓你同時開很多個 Coding Agent，附提醒光圈、可程式化的瀏覽器面板與 CLI。Pyloxa 是 Windows 10/11 的 App：大腦規劃工作，你的規則把每個工作派給 Claude Code 或 Codex CLI，各自在自己的 git worktree 裡做，Pyloxa 跑完你的驗證再讓你合併。用 Mac、想自己操控任何終端機 Agent，選 cmux；用 Windows、想把規劃、驗收與額度換手交給工具處理，選 Pyloxa。

cmux 做得好的地方

  • 任何 Agent，真正的終端機。每個 CLI Agent 不用整合就能跑，每個 Session 的完整輸出都看得到。
  • 一眼看出誰在等你。Agent 在等輸入時，它的面板會出現藍色光圈、分頁會亮起來。側邊欄顯示每個 Workspace 的 git 分支、連結的 PR、監聽中的 port 與最新通知。
  • 終端機旁邊就有瀏覽器。瀏覽器面板可以用程式點擊、填表單、執行 JavaScript、讀取 console 與網路紀錄，Agent 能自己檢查網頁改動。
  • 什麼都能寫腳本。CLI 與 Unix socket 可以建立 Workspace、分割面板、送出輸入、讀取畫面。專案專用的動作寫在 cmux.json。
  • 遠端工作。cmux ssh 在另一台機器上開 Workspace；付費方案還有 Cloud VM 與 iOS App。
  • 開源又原生。用 Swift 與 AppKit 寫成，沿用你的 Ghostty 設定，而且免費。

Pyloxa 的不同之處

cmux 把自己定位成讓你組裝的基本元件；Pyloxa 是一套固定的流程，每一步怎麼走由你設定。

  • 它會規劃與派工。大腦把需求拆成階段與工作，分工表決定每一類工作交給哪個 Agent。詳見工作流程。
  • 它自己驗收。Agent 說做完了不算數。Pyloxa 會跑你的測試、建置與 lint 命令，檢查有沒有超出計畫的寫入範圍，也可以請第二個 Agent 補測試。整個計畫完成後有一張驗證報告卡，可以附在 PR 上。詳見驗證。
  • 額度換手。標題列顯示每個 Agent 還剩多少額度。某個用完時，經你確認，另一個 Agent 從已經改好的檔案接著做。詳見額度與備援。
  • 合併由你決定。Pyloxa 不會對你的工作目錄做 stash 或 reset，你決定之前什麼都不會合併或推送。

Pyloxa 沒有的東西：終端機或瀏覽器面板、公開的 CLI 或 socket API，以及遠端執行。它只跑 Claude Code、Codex CLI，以及實驗性支援的 Gemini CLI。免費版一次最多兩個工作，同一時間只有一個專案在跑。Pyloxa 不開源、只支援 Windows，安裝檔還沒有程式碼簽章，第一次執行時 SmartScreen 可能會警告。結束 Pyloxa 會停掉它的 Agent。

該選哪一個

  • 選 cmux，如果你用 Mac、想在真正的終端機裡自己操控 Agent、會用 Claude Code 與 Codex 以外的 Agent、需要可程式化的瀏覽器或 SSH Workspace，或偏好能自己延伸的開源工具。
  • 選 Pyloxa，如果你在 Windows 上用 Claude Code 與 Codex CLI，想在一個 App 裡完成計畫、依規則派工、各自的 worktree、用你自己的命令判斷「做完了沒」以及額度換手，合併留給你自己。

可以兩個一起用嗎？

同一台電腦不行：cmux 在 macOS 上，Pyloxa 在 Windows 上。如果你同時有 Mac 與 Windows 電腦，可以各自對同一個 repo 使用。Pyloxa 的「同步到各 CLI」會把專案規則寫進 AGENTS.md，你 commit 之後，在 cmux 裡跑的 Agent 也拿得到。詳見三個 CLI 共用一份指示檔。

常見問題

cmux 有 Windows 版嗎？
目前沒有。cmux 的 README 寫著只支援 macOS（“macOS only, for now”），最新的 GitHub Release 也只有 macOS 的下載檔。如果你想找能在 Windows 上讓 Claude Code 與 Codex 一起做同一個專案的 App，Pyloxa 是一個選擇，只是做法不同。
cmux 能跑 Claude Code 和 Codex 嗎？
可以。cmux 能跑任何在終端機裡執行的 Agent，README 也點名了這兩個。它還有 cmux claude-teams 可以開 Claude Code 的 teammate 模式，以及讓 Codex 與 Claude Code 接續 Session 的 hooks。
cmux 免費嗎？Pyloxa 呢？
cmux App 免費且開源，付費方案加上 Cloud VM 與 iOS App。Pyloxa 免費版不需要帳號；Pro 每年 US$79（早鳥 US$49），免費預覽到 2026 年 12 月 31 日，12 月 1 日起開賣。兩者都用你自己的訂閱或 API Key 跑 Agent。
cmux 會建立 git worktree 嗎？
worktree 不在它列出的功能裡，不過自訂命令文件有一個範例「Agents in New Worktree」，會建立一個 worktree 並在裡面開 Codex 與 Claude Code。Pyloxa 會替每個工作建立 worktree。
