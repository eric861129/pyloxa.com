Pyloxa/攻略/Claude Code 額度用完怎麼辦

攻略

Claude Code 說「usage limit reached」，接下來怎麼辦？

Pro、Max、Ultra 訂閱的 Claude Code 額度怎麼算、怎麼看什麼時候重設，以及怎麼讓工作繼續、不弄丟進度，也不違反條款。

更新於 2026 年 11 月 19 日

簡短回答

Pro 或 Max 訂閱的 Claude Code 和 claude.ai 共用同一份額度：一個從你送出第一則訊息起算、5 小時後重設的 Session 額度，再加上每週額度。用完時先跑 /usage 看什麼時候重設。接著可以等（新版 Claude Code 會在重設後自動接著做被中斷的工作）、開啟依 API 費率計費的 usage credits、把 Claude Code 改成用 Console 的 API Key，或是先 commit，再交給另一個 Agent 接手。輪流用好幾個帳號來躲額度，違反 Anthropic 的條款與使用政策。

Claude Code 的「usage limit reached」是什麼意思

Pro、Max、Ultra 訂閱同時涵蓋 claude.ai、Claude Desktop 與 Claude Code，三邊共用同一份額度，在哪裡用都算進同一個上限。

  • Session 額度：從你送出第一則訊息開始算，5 小時後整份重設。通過驗證的 Ultra 帳號沒有 5 小時限制。
  • 每週額度：所有模型合計，每個帳號有固定的每週重設時間。Max 與 Ultra 另外還有 Fable 模型專用的每週額度。
  • 兩個同時扣：用量會同時算進 Session 與每週額度，所以一次大量使用，可能在 Session 重設前就把整週額度用完。

Anthropic 沒有公布這些額度等於幾則訊息或多少 token，也保留調整的權利。用得快慢取決於模型、思考強度、對話長度，以及用到的工具與連接器。

訊息意思
You've hit your session limit · resets 3:45pm5 小時的 Session 額度用完了，換模型沒有用。
You've hit your weekly limit · resets Mon 12:00am每週額度用完了，換模型沒有用。
You've hit your Opus limit 或 Sonnet limit只有這個模型家族受限，用 /model 換到別的家族就能繼續。
Usage limit reached · wrapping up回應到一半撞到 5 小時額度，Claude Code 可能會把目前這一步做完。Pro 每週最多一次，而且不適用於新訊息。

怎麼看額度還剩多少、什麼時候重設？

  • /usage（也可以打 /cost、/stats）：顯示訂閱額度的用量條、重設時間，以及額度花在哪裡的明細與改善建議。明細只算這台電腦上的用量。
  • /status：顯示目前用的帳號與登入方式，確認你是在用訂閱還是 API Key。
  • claude.ai → Settings → Usage：目前 Session 的用量、剩餘時間與下次每週重設時間，涵蓋所有 Claude App。

快用完前，Claude Code 會先提醒，例如 You've used 85% of your session limit · resets 3:45pm。看到這個訊息時，就是 commit、寫交接筆記的時機，因為這時 Claude 還能幫忙。

額度用完時可以怎麼做？

  1. 等額度重設從 v2.1.234 開始，用訂閱登入的互動式 Session 只要保持開著，重設後會自己接著做：Continuing automatically at 3:45pm · Esc to cancel。如果重設時間在 24 小時以後（常見於每週額度），到 /rate-limit-options 選「Wait here, then continue automatically」。
  2. 開啟 usage creditsusage credits（以前叫 extra usage）讓 Pro、Max、Ultra 在額度用完後繼續用。執行 /usage-credits，或到 claude.ai → Settings → Usage 打開 Usage credits、設定每月花費上限，再購買額度。這是預付制，依標準 API 費率計費，另外加在訂閱費之外，而且不退款。
  3. 把 Claude Code 改成用 API Key把 ANTHROPIC_API_KEY 設成 Claude Console 的 API Key，並在詢問時同意使用，或用 /login 登入 Console 帳號。之後每個 token 都依 API 費率計費，沒有重設時間可等。要換回訂閱，移除這個環境變數再用 /status 確認；忘了移除，就會一直用 API Key 計費。
  4. 改用比較輕的模型遇到 Opus 或 Sonnet 額度時可以靠換模型繼續，平常也能讓剩下的額度撐久一點。Anthropic 建議大部分寫程式的工作用 Sonnet，困難的推理再用 Opus；/effort 可以降低思考強度。
  5. 升級方案從 Pro 升到 Max，或從 Max 升到 Ultra，基本額度會變高。目前的方案請看 claude.com/pricing。

怎麼讓額度撐久一點？

Claude Code 每次請求都會送出整段對話，所以 context 越大，用得越快。Anthropic 的成本指南建議：

  • 換不相關的工作就 /clear。它不花額度。之後還想回來，先用 /rename 取名，再用 /resume 找回。
  • 需要延續時，用 /compact 加上重點說明。壓縮很大的 context，本身就是一次大請求。
  • 要求要具體。「在 auth.ts 的 login 函式加上輸入驗證」比「改善這個 codebase」少讀很多檔案。
  • CLAUDE.md 保持精簡（文件建議 200 行以內），不常用的指示搬到 Skills。
  • 關掉沒在用的 MCP server：用 /mcp；/context 可以看 context 被什麼佔掉。
  • 注意閒置的 Session。Loop、排程工作與 goal check-in 在閒置時也可能送出整段 context，每個 subagent 也會各自發出請求。

怎麼把沒做完的工作交給 Codex 或其他 Agent？

另一個用自己訂閱的 Agent，例如用 ChatGPT 帳號登入的 Codex CLI，可以接手做下去。它看得到的是你的檔案與 git，看不到 Claude 的對話，所以要把東西都放進去。

  1. 放到一個分支上先看 git status，確定沒有機密檔案會被 commit，再把現有的變更 commit 起來，還不能 build 也沒關係。
  2. 寫一份簡短的交接筆記目標、做完了什麼、還剩什麼、重要的檔案、怎麼測試、已知的問題。看到額度提醒時就請 Claude 寫；額度已經用完的話，自己寫。
  3. 讓兩個 Agent 讀同一份專案指示Codex 開始工作前會讀 AGENTS.md。Claude Code 在沒有 CLAUDE.md 時會讀 AGENTS.md；或在 CLAUDE.md 第一行寫 @AGENTS.md，兩邊就讀同一份。
  4. 讓下一個 Agent 從筆記開始在 repo 裡開 Codex，請它讀筆記後繼續。記得在 Codex 裡跑 /status：它也有自己的額度。
git status
git switch -c wip/limit-handoff
git add -A
git commit -m "WIP: handoff from Claude Code (usage limit)"
codex "Read HANDOFF.md and AGENTS.md, run the tests, then continue the remaining items."

可以開好幾個 Claude 帳號來繞過額度嗎？

不要。Pro、Max、Ultra 適用 Anthropic 的 Consumer Terms，條款禁止把帳號登入資訊分享給任何人。Anthropic 的使用政策（Usage Policy）在「Do Not Abuse Our Platform」底下，禁止刻意繞過產品內建的限制，也禁止為了躲避偵測而建立多個帳號。輪流換帳號躲額度，或幾個人共用一個訂閱，牽涉到的每個帳號都有風險。一個方案不夠用時，正當的做法是 usage credits、升級方案、API Key，或用你自己訂閱的另一家 Agent。

Pyloxa 能幫上什麼

Pyloxa 是有免費版的 Windows App，用你自己的訂閱執行 Claude Code 與 Codex CLI，上面的換手流程它會幫你處理。每個工作都在自己的 git worktree 與分支上執行，所以撞到額度時，做到一半的成果已經在檔案與分支裡。

  • 免費版：標題列顯示 Claude Code 還剩多少額度（取 5 小時與 7 天中比較緊的那個，和 claude.ai 與終端機共用）。某個 CLI 額度用盡時，Pyloxa 停止派工給它，依你的規則提出備援；你確認後，另一個 CLI 從已經改好的檔案接著做，也可以選「額度恢復後重試」。等待中的工作會在重設後繼續。
  • Pro：依你設定的備援順序自動接手，預設關閉，每個工作最多換手 2 次。另外還有專案優先序、每條連線的額度估計，以及在下次額度重設後才開始的排程計畫。
  • 用訂閱的工作不會自己改成 API Key 計費。

如果你只用 Claude Code，它內建的自動繼續就能處理「等重設」，這部分不需要 Pyloxa。詳見 額度與備援、Agent 額度用盡時 與 Pro。

常見問題

Claude Code 的額度什麼時候重設？
Session 額度在那個 Session 第一則訊息的 5 小時後重設；每週額度在你帳號固定的每週時間重設。錯誤訊息會寫重設時間，/usage 與 claude.ai → Settings → Usage 兩者都看得到。
claude.ai 聊天和 Claude Code 共用同一份額度嗎？
是。Pro、Max、Ultra 在 claude.ai、Claude Desktop 與 Claude Code 的使用，都算進同一份 Session 與每週額度。
換成 Sonnet 或 Haiku 能繞過額度嗎？
Session 與每週額度不行，因為它們是所有模型合計。如果看到的是 Opus 或 Sonnet 額度的訊息，換模型就能繼續；平常用輕一點的模型，也能讓剩下的額度撐久一點。
額度用完時，Claude Code 會自動刷我的卡嗎？
用訂閱時不會，除非你自己開啟並購買 usage credits。但如果設定了 ANTHROPIC_API_KEY 並同意使用，就會依 token 計費；不確定時用 /status 看目前是哪一種。
Codex 能從 Claude Code 停下的地方接著做嗎？
它是從檔案與 git 分支接著做，看不到 Claude 的對話。所以 commit 好的分支和一份簡短的交接筆記很重要：下一個 Agent 需要的脈絡都在裡面。
