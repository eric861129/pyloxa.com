Pyloxa für Windows herunterladen

Kostenlos und ohne Konto. Pyloxa führt die CLIs von Claude Code und Codex aus, die du schon nutzt, mit deinen eigenen Abos oder API-Schlüsseln.

Dein Download hat begonnen. Falls nichts passiert, nimm den Button unten.

Installer herunterladen v0.2.0 · 130.5 MB · Windows 10 und 11, 64-Bit

12 Releases seit November 2026, jedes mit Release Notes und SHA-256-Prüfsumme.

In vier Schritten installiert

  1. Installer ausführenDer Installer ist noch nicht code-signiert, daher meldet Windows eventuell, dass dein PC geschützt wurde. Wähl „Weitere Informationen“ und dann „Trotzdem ausführen“.
  2. Den Einrichtungsassistenten prüfen lassenEr prüft git (erforderlich) und Node.js (optional). Fehlt etwas, zeigt er den winget-Befehl oder die offizielle Downloadseite. Mit Node.js installiert er Claude Code oder Codex CLI nach deiner Bestätigung mit dem offiziellen npm-Befehl.
  3. Bei deinen Agenten anmeldenMelde dich mit deinem eigenen Abo bei Claude Code oder Codex an oder füge einen API-Schlüssel hinzu. Pyloxa liest, kopiert oder sendet deine CLI-Anmeldungen nie.
  4. Eine Probefahrt machenBevor du dein eigenes Projekt öffnest, probier Pyloxa an einem kleinen Beispielprojekt mit verstecktem Fehler aus. Die Probefahrt braucht Node.js, fasst deine Projekte nie an, pusht nichts und öffnet keinen PR.

Was du brauchst

  • Windows 10 oder 11, 64-Bit
  • Git for Windows 2.30 oder neuer
  • Claude Code oder Codex CLI, angemeldet mit deinem eigenen Abo oder mit einem API-Schlüssel. Mit beiden kann Pyloxa die Arbeit aufteilen und übergeben, wenn einem das Kontingent ausgeht.
  • Node.js 22 oder neuer, nur wenn der Einrichtungsassistent die CLIs für dich installieren soll oder für die Probefahrt

Die kostenlose Version braucht kein Konto, und Pyloxa sendet deinen Code oder deine Prompts nie an uns.
